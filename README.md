## 📌 Loyiha haqida
Ushbu loyiha mehmonxonalar, xonalar va ularni bron qilish (band qilish) jarayonlarini boshqarish uchun moʻljallangan loyiha hisoblanadi. Tizim fanning 15 ta laboratoriya topshirigʻiga muvofiq, versiyalarni boshqarishdan tortib konteynerlashtirish va avtomatlashtirilgan sinovlargacha boʻlgan bosqichlarni oʻz ichiga oladi.

## 🛠 Texnologik stek (Tech Stack)
* **Dasturlash tili:** Python 3.12+
* **Backend Framework:** Django
* **Ma'lumotlar bazasi:** SQLite / PostgreSQL
* **Konteynerizatsiya:** Docker & Docker Compose
* **Xavfsizlik & Autentifikatsiya:** JWT & RBAC
